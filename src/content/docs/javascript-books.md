Platform scripting needs language knowledge more than framework knowledge, and the two are sold together. This index marks which titles teach the language itself.

## JavaScript Books
A short shelf of real books teaches more than a long list of links. Start with a language guide that explains closures, prototypes, and the event loop properly, then add Kyle Simpson's You Don't Know JS series for depth. A browser platform book covers the DOM and fetch. Read each one twice, once for the argument and once for the code, and keep notes beside the scripts you maintain.
