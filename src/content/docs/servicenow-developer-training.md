The scripting surface is broad, but the order to learn it is narrow. This page follows the sequence that produces working artefacts earliest, starting with server-side scripts and forms.

Who should watch the Training:
### GETTING STARTED
The GlideForm client API touches almost every form task: reading a field, making it mandatory, or hiding it when a condition holds. A recorded walkthrough of those calls shows which ones run at load and which run on change. Learn the pattern once and the same code serves incident, change and custom tables.
