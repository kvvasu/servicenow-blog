## Tips and Tricks
Platform knowledge compounds, and small tricks add up. A habit of filtering a GlideRecord by an indexed field on every script prevents a whole class of slow transactions. Keep a running list of the settings and query habits that earn time back. Test each one in a personal developer instance before trusting it. Share the list with a teammate, because explaining a trick exposes the parts you never understood.
