## Let's Learn ECMAScript 2021 with Earl Duque
Earl Duque's session covers ECMAScript 2021 features and where they apply inside ServiceNow. Optional chaining and nullish coalescing shrink guard clauses in client scripts and Script Includes, but every runtime context does not necessarily support every feature. Test a construct in the target scope before adopting it. Learning the syntax matters less than knowing which runtime executes it.
