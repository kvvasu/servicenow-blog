## Chuck Tomasi
Chuck Tomasi's JavaScript series on the Now Platform introduces variables, functions, and objects before applying them to GlideRecord and GlideSystem. Developers who already write scripts on the platform still gain from the series, because it separates plain JavaScript behaviour from platform API behaviour. That distinction matters when a script fails: the cause is often a language mistake, not a platform call.
