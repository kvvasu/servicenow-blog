Low-code builders are fast for some applications and a dead end for others. This page keeps the episode notes together with how to tell which one you have.

## Learn how to create ServiceNow builder app with Chuck Tomasi
A ServiceNow application rarely stays a single table and a form. You define a scoped app so its objects carry a namespace and travel cleanly between instances. Chuck Tomasi builds one step by step, adding tables, forms, business rules, and a script include behind an interface. The remaining effort goes into access control, logging, and update sets, which the demo often hides. Skipping those pieces produces an app that works in the developer instance and fails during promotion.
### Builder Series
The Builder series walks through Guided Application Creator. A developer answers prompts, and the platform generates a scoped app with tables, roles, and a workspace. It suits a newcomer who wants a working skeleton before learning the metadata underneath. Generated apps still need review. Confirm the generated roles grant the least access the job needs, and check that tables landed in the intended scope. Treat the output as a first draft.
