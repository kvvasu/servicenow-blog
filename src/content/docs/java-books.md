Java appears around the platform in integrations and in some tooling, so a working knowledge helps. This index marks the level each title assumes.

## Java Books
ServiceNow executes JavaScript on the server, so a Java book does not teach the platform directly. It still pays off. Java material explains types, the call stack, threading, and object design more rigorously than most scripting tutorials. A developer who understands those fundamentals writes cleaner script includes and reads a stack trace faster. Read Java for the concepts, then translate them into the JavaScript the platform actually runs. Never paste Java syntax into a Business Rule.
