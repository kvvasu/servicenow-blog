GraphQL changes the question from which endpoint to call to which fields you need. This page keeps the episode notes together with where GraphQL fits beside the platform's REST APIs.

## Learn GraphQL on the ServiceNow platform with Chuck Tomasi
GraphQL lets a client ask for exactly the fields it needs rather than pulling a whole record. ServiceNow exposes GraphQL through its API surface, so a mobile app can read incident fields and comments in one round trip. Chuck Tomasi walks through query shape, schema exploration, and error handling in a video series. The query language pays off when a REST integration returns too much data or makes too many calls. Practice on a personal developer instance before touching a customer list.
