The ECMAScript 2021 session covers the language-level features that reach platform scripting, and the examples are worth reproducing rather than reading.

## Let's Learn ECMAScript 2021 with Earl Duque
ECMAScript 2021 added features a platform developer can use today. Promise.any resolves when the first request succeeds and ignores the ones that reject. String.replaceAll removes a loop that developers wrote by hand for years. Logical assignment operators shorten a null check into one line. WeakRef and FinalizationRegistry exist for memory-sensitive work, though most scripts rarely need them, so treat them as advanced tools rather than habits.
