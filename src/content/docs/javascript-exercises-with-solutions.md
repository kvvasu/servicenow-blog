Server-side scripting rewards a small set of language habits: explicit checks, predictable types and no reliance on coercion. These exercises are useful because they build those habits deliberately rather than by accident.

## JavaScript Exercises with Solutions
An exercise only works when the solution teaches more than the answer. A good set builds one skill at a time: array methods, then closures, then asynchronous control flow, then error handling. Each problem should ship a runnable solution with a short note on the tradeoff chosen. Attempt the problem first, compare against the solution, then rewrite your version. Reading solutions without writing code builds recognition, not skill.
