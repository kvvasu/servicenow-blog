## Göran Lundqvist
Göran Lundqvist publishes short ServiceNow episodes that walk through one feature at a time, filmed against a real instance. Each episode shows the configuration screen, the script, and the result, which suits developers who learn by watching behaviour instead of reading a reference page. The format stays narrow on purpose, so a viewer leaves knowing how one object works rather than skimming many.
### ServiceNow Episodes
An episode on UI Policy shows how a client-side rule hides a field or makes it mandatory when another field changes. The value comes from execution order. A UI Policy runs before a Client Script on the same form. A script that reads a field the policy controls must account for that sequence. Watching both run side by side explains behaviour that a written page states but rarely shows.
