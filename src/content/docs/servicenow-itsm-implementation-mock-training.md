ITSM implementations fail on process decisions more often than on configuration. This mock walkthrough surfaces those decisions early, so the technical work has something to implement.

Who should watch the Training:
### GETTING STARTED
The training opens with setup, then moves into configuring the Incident form. A student needs a personal developer instance before the first exercise, plus the admin role to reach form design. Configure the form early because later exercises reference those fields. Skip the setup module and every following lesson breaks in a way that looks like a bug rather than missing preparation.
